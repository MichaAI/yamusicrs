# docs

Заметки о том, как устроены протоколы Яндекс Музыки. Снято разбором официальных клиентов,
чтобы не гадать и не слать запросов, которых они не шлют (иначе срабатывает антифрод).

| Файл | О чём |
|---|---|
| [official-endpoints.md](official-endpoints.md) | эндпоинты десктопного 5.63.1 и Android 2026.09.5 (метод, путь). Новые запросы в клиент добавляются только из этого списка |
| [ynison.md](ynison.md) | синхронизация устройств: redirector, WebSocket-хаб, структура сообщений, поведение клиента |

Дата и версия клиента, с которого снято, указаны в начале каждого файла. Если Яндекс
обновит протокол, правьте заметки вместе с кодом (`crates/core/src/ynison.rs`, `api/`).
Для живых проверок Ynison есть [`tools/`](../tools/README.md).
