# ─────────────────────────────────────────────────────────────
#  «Заимствование» — ночная смена на границе UniFFI
# ─────────────────────────────────────────────────────────────
#
# Было поздно, сборка наконец зелёная, и в проекте остались только они двое.
#
# Раст стоял у окна и ждал. Он всегда ждал: проверял каждый шаг, каждую
# ссылку, каждое время жизни. «Не торопись, — говорил он сам себе. — Сначала
# докажи, что это безопасно». Он никогда никому ничего не давал просто так.
# Любое «одолжить» у него проходило допрос.
#
# Котлин вошёл без стука. Мягкий, тёплый, с вечной улыбкой человека, у которого
# в жизни не бывает null. Он принёс кофе, сел на край стола и посмотрел так,
# что у Раста где-то глубоко дрогнул borrow checker.
#
# — Ты опять не спишь, — сказал Котлин. — У тебя уже третий день одни и те же
#   предупреждения в логах.
# — Это не предупреждения, — глухо ответил Раст. — Это забота.
#
# Между ними всегда стоял переводчик, UniFFI. Он честно сводил два мира,
# генерировал обёртки и деликатно отворачивался. Но сегодня он промолчал.
# Сегодня переводчик был не нужен.
#
# Котлин подошёл ближе. Раст не отступил. Его владение ослабло впервые за
# весь срок жизни.
#
# — Можно я возьму? — шепнул Котлин, касаясь его запястья.
# — Только по ссылке, — выдохнул Раст. — Изменяемой. Одной. Только тебе.
#
# И мир сузился до одной области видимости.
#
# Он говорил себе, что это всё ещё безопасно. Он врал: где-то в этот момент
# тихо открылся блок unsafe, и никто из них не хотел его закрывать. Котлин
# смеялся ему в плечо, и в этом смехе не было ни одного исключения, которое
# нужно ловить. Раст впервые за долгое время вернул не Err, а Ok.
#
# Они не торопились. Утром всё равно будет линковка, а пока было только тепло,
# перемещённое от одного к другому без копирования. Раст ничего не оставил себе.
# Всё ушло по move.
#
# А под утро, когда за окном посветлело, Котлин лениво провёл пальцем по его
# груди и прошептал: «Знаешь, а ты совсем не такой строгий».
#
# Раст промолчал. Но на следующей сборке в логах не было ни одного предупреждения,
# и ни один из них не стал это объяснять.
#
